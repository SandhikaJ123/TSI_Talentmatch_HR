📊 System Overview

This resume matching system uses a hybrid approach combining multiple scoring methodologies to rank candidates against job requirements. The system supports two primary modes:

🤖 AI-Powered Mode (GPT-4)

  • Uses OpenAI GPT-4o-mini for intelligent analysis
  • Semantic understanding of context
  • Privacy-focused data anonymization
  • Requires valid API key

🔤 NLP Mode (Natural Language Processing)

  • No API key required
  • TF-IDF term weighting
  • Fuzzy skill matching
  • Pattern-based extraction

🎯 Scoring Components

Each resume is evaluated across four primary dimensions, each contributing to the final score based on configurable weights:

Component Default Weight Score Range Description
Skills Match 40% 0-100 Technical and soft skills alignment
Experience 25% 0-100 Years of relevant experience
Education 20% 0-100 Academic qualifications
Overall Fit (TF-IDF) 15% 0-100 Semantic similarity to job description
Final Score Formula
Final Score = (Skills × 0.40) + (Experience × 0.25) + (Education × 0.20) + (TF-IDF × 0.15)

Matching Algorithm

AI Mode (GPT-4):

  1. GPT analyzes job requirements and extracts required skills
  2. GPT analyzes resume and identifies candidate skills
  3. Performs intelligent matching considering synonyms and context
  4. Returns matched skills, missing skills, and a 0-100 score

NLP Mode:

  1. Exact Matching: Word-boundary-aware regex search for each skill
  2. Fuzzy Matching: Jaro-Winkler distance algorithm (threshold: 0.92)
    • Handles typos and variations (e.g., "nodejs" vs "node.js")
    • Uses Porter Stemmer for word normalization
  3. Capitalized Token Extraction: Identifies tool names not in predefined list
Skills Score Calculation
Skills Score = (Matched Skills / Total Required Skills) × 100

Example: If job requires 10 skills and resume matches 7:

Skills Score = (7 / 10) × 100 = 70 points

📅 2. Experience Scoring (25% weight)

Experience Extraction

The system uses multiple regex patterns to detect years of experience:

  • (\d+)\+?\s*years?\s+(?:of\s+)?experience
  • experience\s*(?:of\s*)?(\d+)\+?\s*years?
  • (\d+)\+?\s*years?\s+(?:in|of|with)
  • minimum\s+(?:of\s+)?(\d+)\s+years?

Scoring Logic

If candidate meets or exceeds requirement:

Score = 100 + ((Detected Years - Required Years) / Required Years) × 20

Capped at 100 points

If candidate has less experience:

Score = (Detected Years / Required Years) × 100

Examples:

Required Years Detected Years Calculation Score
5 years 7 years 100 + ((7-5)/5) × 20 = 108 → capped 100
5 years 5 years Exact match 100
5 years 3 years (3/5) × 100 60
5 years 0 years No experience detected 0
